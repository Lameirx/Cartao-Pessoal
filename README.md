# **Perfil Profissional - Estética Frutiger Aero**

*Este projeto consiste em uma página de perfil profissional responsiva inspirada no estilo estético Frutiger Aero (popular entre meados dos anos 2000 e início dos anos 2010 em sistemas como Windows Vista e Windows 7). O design conta com elementos transparentes em vidro (Aero Glass), degradês vibrantes, bordas glossy e um sistema de partículas animadas em canvas (bolhas flutuantes).*

# Demonstração de Recursos

* Design Frutiger Aero / Glossy: Interface estilizada utilizando transparências (backdrop-filter), reflexos de luz, cantos arredondados e gradientes inspirados na era Skewmórfica.

* Navegação por Abas Internas: Interface dinâmica que permite alternar entre as seções "Sobre Mim", "Habilidades" e "Contato" sem recarregar a página.

* Animação de Fundo Interativa: Efeito dinâmico de bolhas em movimento gerado via HTML5 Canvas em tempo real.

* Ações Rápidas: Integração com links externos e funcionalidade para copiar o endereço de e-mail diretamente para a área de transferência.

* Design Responsivo: Layout otimizado para navegação em dispositivos móveis e desktops.

### Tecnologias Utilizadas

* HTML5: Estruturação semântica do conteúdo.

* CSS3 / Tailwind CSS: Utilitários de estilização, propriedades customizadas para sombras em camadas, gradientes complexos e efeitos glassmorphism.

* JavaScript (Vanilla): Lógica de alternância de abas, cópia de e-mail e renderização da física de partículas do canvas.

* Font Awesome: Conjunto de ícones vetoriais.

* Google Fonts: Tipografia baseada em Segoe UI.
